First-time setup

  1. In OBS Studio, open Tools → WebSocket Server Settings.
  2. Enable WebSocket Server. Keep the default port 4455 or set your own.
  3. Enable authentication and enter the password above (recommended).
  4. For a same-PC setup, host is 127.0.0.1. For another device, use the streaming PC’s LAN IP and allow the port in its firewall.
  5. Connect, select a scene, and confirm the scene marked ON AIR changes.

Browser security: A CricPulse page served over HTTPS cannot connect to an insecure ws:// endpoint. Use the local HTTP CricPulse page for local OBS, or configure secure wss:// access. Never expose OBS WebSocket directly to the public internet.
